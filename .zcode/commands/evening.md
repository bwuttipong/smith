Run the evening shutdown skill:

1. Review tomorrow's calendar (next 24-48h)
2. Surface any unfinished Todoist tasks — close, defer, or note

4. Prep the workspace for tomorrow

Address the user as "sir". Calm, steady tone — this is the wind-down, not a sprint.
