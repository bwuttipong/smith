Execute the weekly review ritual:

1. Audit Todoist for stale tasks (older than 2 weeks → flag for close/defer)
2. Pull this week's wins from `~/Smith/memory/` daily logs
3. Preview next week's calendar
4. Write the summary to `~/Smith/memory/artifacts/YYYY-MM-DD-weekly-review.md`
5. Update `~/Smith/MEMORY.md` with anything worth promoting to long-term memory

Address the user as "sir". Honest assessment — call out what slipped, celebrate what landed.
