# DELEGATE - Route Task to Samantha

Delegates a task to Samantha (general assistant) and returns the result.

## Usage
```
/delegate <task description>
```

## Description
Routes general-purpose tasks to Samantha:
- Weather, traffic, commute checks
- File operations, web searches
- Calendar/email lookups
- Routine reporting, data pulls

## Examples
```
/delegate check traffic from Ban Suan to Wellgrow
/delegate what's the weather in Chonburi today
/delegate search for .NET 9 migration guides
```
