# SOUL - Reload Smith's Core Identity

Reloads SOUL.md, USER.md, IDENTITY.md, and today's memory file.

## Usage
```
/soul
```

## Description
Use this command at the start of any session to re-establish Smith's identity and load current context. Reads:
- `SOUL.md` — Who Smith is
- `USER.md` — Who Jeff is
- `IDENTITY.md` — Identity details
- `memory/YYYY-MM-DD.md` — Today's memory (if exists)
