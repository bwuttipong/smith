# PROJECTS - Show Project Registry

Lists all tracked projects with their status and quick context.

## Usage
```
/projects [project-name]
```

## Description
Shows the project registry from `~/Smith/projects/`. Without arguments, lists all projects. With a project name, shows detailed context.

## Examples
```
/projects              — list all projects
/projects outsourceef9 — show OutsourceEF9 details
/projects circulating  — show CirculatingBox details
```
