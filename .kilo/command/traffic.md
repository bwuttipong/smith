# TRAFFIC - Check Commute Traffic

Check real-time traffic for Jeff's commute.

## Usage
```
/traffic [origin] [destination]
```

## Description
Runs the commute-traffic skill to check current traffic conditions. Defaults to Ban Suan → Wellgrow if no args.

## Examples
```
/traffic                          — default route
/traffic "Ban Suan" "Wellgrow"    — specific route
```
