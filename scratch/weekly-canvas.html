📊 MRP & Manufacturing Flow Diagram

flowchart TD
    CO[Customer Order]
    JOQTY[Job Order Qty Released]
    MRP[MRP Engine]
    MW[Material Planner Workbench]
    BOM[Job BOM Explosion]
    CREF[Item Cross-Reference]
    POHIST[PO History]
    FPO[Firm Planned PO]
    BLPO[Backlog POs / Past Due]
    TFI[Time-Phased Inventory]
    PDD[Planning Detail Display]

    CO --> JOQTY
    JOQTY --> BOM
    JOQTY --> CREF
    JOQTY --> MRP
    MRP --> MW
    MW --> FPO
    MW --> BLPO
    MW --> TFI
    TFI --> PDD
    CREF -.-> POHIST

Flow Logic:

  • Demand Entry: Customer Order triggers Job Order Qty Released (form: Job Order Create)
  • Parallel Processing: Job BOM Explosion (material requirements) + Item Cross-Reference (alternate parts)
  • MRP Engine: Runs regeneration or net-change; outputs planned orders to Material Planner Workbench
  • Material Planner Workbench: Branches into Firm Planned POs, Backlog POs (past due), and Time-Phased Inventory view
  • Output: Time-Phased Inventory feeds Planning Detail Display for final visibility

🛠 Easy Issue Troubleshooting

Issue 1: Ref Type is (Blank) for JOB...

  • Select the Customer Orders form
  • Input the Order: #K*2487
  • Click Filter In Place
  • Go to Lines: #1 (at the right bar menu side)
  • Go to Releases: #1
  • Go to Source
  • Click the References tab and set: Destination = Order, Order Number = #K000012487, Order Line = #1, Order Release = #1

Note: The cross-references on top of the error specify the Order Line and Order Release numbers.

Issue 2: PO Requisition Line that has x does not exist...

  • Select the Job Orders form
  • Input the Job
  • Click the Filter icon
  • Go to Operations
  • Go to Materials
  • Click the Source tab and set the Source to Inventory

Issue 3: Outdated planning recommendation (Job/PR) remains active for an item...

  • Select the Material Planner Workbench form
  • Uncheck Purchase Order (or select off the Purchase Order filter)
  • Uncheck All Orders filter in the Filter group
  • Select the target item on the table (e.g., #K0002666)
  • Deactivating and Archiving the Source Job:
    • Click the Time Phased button
    • Click the Source button
    • Click the Job button
    • Change the status to Stopped
    • Click the Save button
    • Change the status to History
    • Click the Save button again to archive
  • Stopping Outdated Purchase Requisitions (PR):
    • Click the Planning Detail button
    • Find the item which has outdated/old yearly Purchase Requisitions (PRs)
    • Select the Purchase Order Requisitions form
    • Input the Requisition number (e.g., #R680000197)
    • Click Filter In Place
    • Change the status to Stopped
    • Click the Save button
    • Click Save again if prompted
