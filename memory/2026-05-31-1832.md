### 🏃 Speed & Performance

**Bun is genuinely faster — but mostly at the edges.**
- Cold starts: ~4x faster than Node (meaningful for serverless)
- Native TS execution: no ts-node/tsx needed, saves real dev time
- But real-world backend perf differences are marginal — Bun peaks on microbenchmarks, not production workloads
- One user reported Node was *more performant* for heavy Redis usage

### 🏭 Production Readiness

**The split is clear: greenfield/hobby → Bun, mature org → Node.**

**Pro-Bun camp says:**
- "Using Bun in production for small projects with Hono — zero issues, very low memory"
- "DX is so much better. I love not needing dozens of dependencies"
- "Bun is much easier to set up, especially for TypeScript"

**Anti-Bun / cautious camp says:**
- "Has crashed every few days on a small dashboard. Our Node backend? Rock solid."
- "We were seeing seg faults on Windows. Private feed auth issues too. No LTS is a problem."
- "Not even a consideration until Datadog tracing/profiling matures"
- Most honest framing: *"it's the 5% that breaks at 3am"*

### 🔧 The Native Module Wall

This is the #1 concrete blocker. Packages like `node-pty`, `xterm.js`, or anything using N-API/node-gyp either don't work or have untested edge cases on Bun. Bun's N-API compat is improving, but packages reaching into V8 internals or assuming libuv behavior cause hard-to-debug failures.

### 🤝 The Anthropic Acquisition (Dec 2025)

This is *polarising*:
- Some see it as validation + staying power ("$1bn acquisition, Claude Code integration")
- Others see it as an existential risk ("Started moving back to Node after the acquisition")
- "I'm still waiting for the enshitification of Bun. Being a commercial project..."

### 📊 The Numbers

Bun's codebase is ~90% native (Zig/C++) vs Node's ~25% native (73% JS). Deno sits at 60% Rust / 40% JS. The Bun camp argues this is why it's faster; critics say "Node's JS layer + libuv is what makes it stable, and Bun's complexity is tech debt disguised as performance."

### 💭 Bottom Line from Reddit

| When Bun wins | When Node wins |
|---|---|
| Greenfield projects | Anything at scale |
| Serverless (cold start) | Enterprise / big org |
| Solo dev / small team | Team with existing Node infra |
| DX-focused (TS, config) | Stability-critical |

**The most upvoted take:** *"Node: community-run, a decade+ old, extremely stable. Bun: VC money, existed for 1/5th as long, segfault reports daily. The idea these are in the same league is a joke — regardless of benchmarks."*

**The counter:** *"Bun's acquisition by Anthropic means it's not going anywhere. It'll likely get *more* attention, not less."*
