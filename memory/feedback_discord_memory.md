When answering questions asked in Discord server channels, use `memory_search` or `memory_get` to pull relevant long-term context from MEMORY.md before responding.

**Why:** User wants context-aware responses across channels, not just within the current conversation thread.

**How to apply:** On any substantive question in a Discord channel (not just check-ins), check memory for relevant context first.
